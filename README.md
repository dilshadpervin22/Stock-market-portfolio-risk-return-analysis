# 📊 Stock Market Portfolio Risk & Return Analysis

## 📌 About the Project

This project is a **financial analytics and portfolio analysis dashboard** designed to evaluate investment performance, returns, ROI, and risk across a stock market investment portfolio.

The project transforms raw investment data into meaningful financial insights using **KPI cards, tables, charts, and interactive visualizations**. It provides a clear overview of portfolio performance and helps identify high-performing investments and asset categories.

## 🎯 Project Objectives

* Analyze overall investment portfolio performance.
* Calculate and evaluate Return on Investment (ROI).
* Compare ROI across different asset types.
* Analyze the amount invested across investments.
* Identify the Top 5 investments based on ROI.
* Understand portfolio risk and return.
* Develop financial KPIs for performance monitoring.
* Convert raw investment data into actionable insights.

## 📊 Dashboard Features

### Investment Portfolio Analysis

Provides a structured view of the investment portfolio, including investment amounts, returns, ROI, and other relevant investment metrics.

### Investment KPI Dashboard

Displays key portfolio metrics in an easy-to-understand format for quick performance evaluation.

### ROI KPI Dashboard

Highlights important ROI metrics to measure the profitability and efficiency of investments.

### ROI Analysis by Asset Type

Compares investment returns across different asset categories to identify better-performing asset types.

### Amount Invested Analysis

Analyzes how investment capital is distributed across different assets and categories.

### Top 5 Investments by ROI

Identifies the five investments generating the highest ROI within the portfolio.

### Portfolio Risk & Return Insights

Evaluates the relationship between investment risk and return to provide a better understanding of portfolio performance.

## 🔍 Key Insights

The dashboard helps users:
